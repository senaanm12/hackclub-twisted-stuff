# HTML5 Elements Guide

An educational website built to help beginners learn, visualize, and understand the purpose of core elements in HTML5.

## 🌐 Live Demo
View the live website here: **[HTML5 Elements Guide](https://github.io)**

---

## 📖 What This Project Does
This project serves as a structured reference guide for foundational HTML5 tags. Instead of just listing definitions, the site demonstrates how HTML elements organize a webpage and includes interactive jump-links so users can quickly navigate between different categories of tags.

### Key Features
* **Quick-Jump Navigation:** Interactive buttons at the top of the page let users jump straight to any section, with **Jump to Top** buttons placed throughout the page for easy browsing.
* **Clear Categorization:** Organizes HTML5 tags into six core topics:
  1. **Heading Elements and Paragraphs:** Explains content hierarchy from `<h1>` to `<h6>` along with `<p>` for body text.
  2. **Structural Containers & Thematic Grouping:** Covers semantic layout elements including `<nav>`, `<main>`, `<aside>`, and `<footer>`.
  3. **Text Formatting & Inline Elements:** Demonstrates how to use `<a>`, `<strong>`, `<em>`, and `<br>`.
  4. **Organized Lists:** Shows how bulleted (`<ul>`), numbered (`<ol>`), and individual list items (`<li>`) work together.
  5. **Media Elements:** Dedicated section for embedding media in HTML5.
  6. **Interactive Form Controls:** Dedicated section for user input and form tags.
* **Built-in Examples & References:** Includes clickable links and dedicated example placeholders for individual elements.

## 🚀 How to Run It
You do not need to install any dependencies or build tools to run this project.

### Option 1: View Online
Simply visit the GitHub Pages link: [https://github.io](https://github.io)

### Option 2: Run Locally
1. Clone this repository or download the project ZIP file:
   ```bash
   git clone https://github.com
   ```
2. Open the project folder.
3. Double-click `index.html` to open it in any web browser (Chrome, Firefox, Edge, Safari, etc.).
